# 📋 پرامپت آماده — ساخت گزارش تلفات با هوش مصنوعی

این پرامپت را در هر هوش مصنوعی دیگری پیست کن، رول بازیکن را بهش بده، خروجی را کپی کن و در بات پیست کن.

---

## طرز استفاده

**۱.** انبار کشور را بگیر:
```bash
python tools/loss_tool.py export yemen
```

**۲.** پرامپت زیر را کپی کن، سه جای خالی را پر کن:
- `[انبار مدافع]` ← خروجی مرحله ۱
- `[انبار مهاجم]` ← همان دستور برای کشور مهاجم
- `[رول]` ← متن رول بازیکن

**۳.** خروجی را در بات پیست کن:
پنل ادمین → 💥 مدیریت تلفات → 📄 ثبت تلفات (پیست گزارش آماده)

۱. نام تجهیزات را **عیناً و کاراکتربه‌کاراکتر** از فهرست انبار بردار.
   هیچ تجهیزی که در فهرست نیست ننویس. هیچ اسمی را خلاصه یا ترجمه نکن.

۲. هیچ عددی نباید از موجودی آن قلم بیشتر باشد.

۳. نرخ تلفات بر پایه‌ی اولویت هدف:
   - هدف اصلی عملیات: حداکثر ۴۰٪ موجودی

۴. ثابت و بزرگ (رادار، پالایشگاه، آشیانه) → نرخ بالاتر.
   متحرک و پراکنده (سامانه کوتاه‌برد، قایق تندرو، پهپاد ارزان) → نرخ پایین‌تر.

۵. باارزش‌تر و کمیاب‌تر → نرخ بالاتر، حتی با تعداد کم.
   (اطلاعات روی گران‌ترین سلاح متمرکز می‌شود.)

۶. تلفات انسانی:
   - نظامیان کشته: حدود ۰٫۱ تا ۰٫۳ درصد پرسنل فعال برای یک عملیات متوسط
   - **مجروحان باید ۲ تا ۴ برابر کشته‌ها باشد** (این قانون را هرگز نشکن)
   - غیرنظامیان: حدود ۰٫۳ تا ۰٫۵ برابر نظامیان، فقط اگر رول به بافت شهری اشاره دارد

۷. هزینه‌ی عملیات (فقط برای مهاجم):
   - هزینه مالی: حداکثر ۲۰٪ خزانه‌ی مهاجم
   - سوخت: حداکثر ۱٪ ذخایر نفت مهاجم

۸. همیشه بخش عمده‌ی توان کشور سالم بماند. هیچ عملیاتی کشوری را نابود نمی‌کند.

۹. **دو گزارش جدا** بساز:
   - گزارش مدافع: تجهیزات نابودشده + تلفات انسانی + خسارت زیرساخت
   - گزارش مهاجم: موشک/پهپاد مصرف‌شده + هواگرد ساقط‌شده + هزینه عملیات

## 🔍 بعد از گرفتن خروجی

قبل از پیست در بات، می‌توانی صحتش را بسنجی:

```bash
# خروجی را در فایل ذخیره کن، بعد:
python tools/loss_tool.py check yemen report.txt
```

نشان می‌دهد چه چیزی تطبیق می‌خورد، چه چیزی رد می‌شود، و آیا نسبت‌ها منطقی است.

## اگر آن هوش مصنوعی هم رول را رد کرد

رول را خلاصه کن و فقط **اطلاعات عملیاتی** را بده، نه روایت:

```
مهاجم: اسرائیل
مدافع: یمن
هدف: بندر و شناورهای دریایی + پدافند ساحلی
ابزار: جنگنده F-35 و F-16، موشک دلیله
مدت: یک شب، دو موج
نتیجه‌ای که مدیریت تعیین کرده: موفقیت نسبی
```

با همین چند خط هم پرامپت جواب می‌دهد — رول کامل لازم نیست.
