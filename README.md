# 🎮 بات بازی «سیاست مدرن» — نسخه اولیه (MVP)

این نسخه اول بازیه. هنوز قرارداد، جنگ، جاسوسی و اخبار توش نیست — این‌ها رو قدم‌به‌قدم اضافه می‌کنیم.
چیزی که الان کار می‌کنه:

- ساخت کشور (`/start`)
- نمایش وضعیت کشور، خزانه، نفت، ارتش
- فروشگاه با دکمه و خرید واقعی تجهیزات/ساختمان/کارخانه/نیروگاه
- درآمد روزانه خودکار (بدون تکرار در یک روز)
- چند دستور ابتدایی ادمین

---

## مرحله ۱: ساخت بات در تلگرام

1. تو تلگرام برو سراغ [@BotFather](https://t.me/BotFather)
2. دستور `/newbot` رو بزن
3. یه اسم و یوزرنیم برای باتت انتخاب کن (یوزرنیم باید به `bot` ختم بشه)
4. بات‌فادر یه **توکن** بهت میده، شبیه این:
   `123456789:AAExampleTokenXXXXXXXXXXXXXXXXXXX`
5. این توکن رو جایی نگه دار — بهش نیاز داری

## مرحله ۲: گرفتن آیدی عددی خودت (برای ادمین شدن)

1. تو تلگرام برو سراغ [@userinfobot](https://t.me/userinfobot)
2. بهت یه عدد میده (مثلاً `123456789`) — این آیدی عددی توئه

سپس فایل `config.py` رو باز کن و داخل `ADMIN_IDS` این عدد رو بذار:

```python
ADMIN_IDS = [
    123456789,
]
```

## مرحله ۳: هاست کردن روی Railway (بدون نیاز به کامپیوتر)

1. یه حساب رایگان تو [railway.app](https://railway.app) بساز (میشه با گیت‌هاب وارد شد)
2. یه حساب گیت‌هاب هم اگه نداری بساز ([github.com](https://github.com))
3. یه ریپازیتوری جدید تو گیت‌هاب بساز و همه‌ی فایل‌های این پروژه رو توش آپلود کن
   (از اپ گیت‌هاب موبایل هم میشه، یا از مرورگر گوشی وارد github.com بشی و فایل‌ها رو Upload کنی)
4. تو Railway بزن روی **New Project → Deploy from GitHub repo** و ریپازیتوری‌ت رو انتخاب کن
5. برو تو تنظیمات پروژه، بخش **Variables** و یه متغیر اضافه کن:
   - نام: `BOT_TOKEN`
   - مقدار: همون توکنی که از بات‌فادر گرفتی
6. Railway خودش `requirements.txt` رو نصب می‌کنه و طبق `Procfile` باتت رو اجرا می‌کنه

بعد از چند دقیقه، برو تو تلگرام سراغ باتت و `/start` رو بزن — باید جواب بده!

## مرحله ۴ (جایگزین): اجرا روی گوشی با Termux

اگه می‌خوای اول محلی تست کنی:

```bash
pkg install python
pip install -r requirements.txt
export BOT_TOKEN="توکن_خودت_اینجا"
python main.py
```

توجه: با این روش، وقتی Termux رو ببندی بات خاموش میشه. برای اجرای ۲۴ ساعته حتماً Railway (یا مشابهش) بهتره.

## ساختار پروژه

```
politics_bot/
├── main.py            # نقطه شروع اجرای بات
├── config.py           # همه قیمت‌ها و تنظیمات (اینجا رو برای تغییر بازی ویرایش کن)
├── database.py         # لایه دیتابیس (SQLite)
├── utils.py             # فرمت کردن اعداد و پول
├── handlers/
│   ├── start.py         # ثبت‌نام کشور
│   ├── country.py       # نمایش وضعیت کشور
│   ├── shop.py           # فروشگاه
│   └── admin.py          # دستورات ادمین
├── requirements.txt
└── Procfile
```

## تغییر قیمت‌ها یا مقادیر اولیه

فقط `config.py` رو باز کن — نیازی به دست‌زدن به بقیه فایل‌ها نیست.

## مراحل بعدی (طبق سند طراحی)

این‌ها رو در گفتگوهای بعدی قدم‌به‌قدم اضافه می‌کنیم:
- سیستم قراردادهای تجاری بین کشورها + فیش مالی
- سیستم فروش تجهیزات و نفت
- سیستم رول جنگی و تلفات
- اخبار و رویدادهای تصادفی
- سیستم دیپلماسی، تحریم، کمک خارجی
- گزارش اطلاعاتی و جاسوسی
- پنل کامل‌تر ادمین (ساخت/حذف کشور، تنظیم قیمت از داخل بات)

هر بار که خواستی یه بخش جدید اضافه کنیم، کافیه بگی کدوم بخش سند رو می‌خوای پیاده کنیم.

## تورنومنت فصلی

- ورود بازیکن: دکمه‌ی `🏆 تورنومنت فصل` یا دستور `/tournament`
- فصل به‌صورت خودکار فعال نمی‌شود؛ ادمین از `/admin` وارد `🏆 مدیریت تورنومنت فصلی` می‌شود.
- ادمین ابتدا پیش‌نویس فصل را می‌سازد، عنوان/مدت/توضیح جایزه را تنظیم می‌کند و سپس با دکمه‌ی `▶️ فعال‌سازی فصل` آن را شروع می‌کند.
- امتیازدهی ترکیبی و بدون سقف نهایی است: اقتصاد، ارتش، دیپلماسی، فعالیت، اهداف استراتژیک و ثبات کشور.
- جدول و جزئیات امتیاز از داخل منوی تورنومنت قابل مشاهده است و snapshot امتیازها به‌صورت دوره‌ای ثبت می‌شود.
- خرید VIP، بسته‌های حمایتی و تزریق ادمین مستقیماً امتیاز تورنومنت ایجاد نمی‌کنند.
